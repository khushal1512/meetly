To ensure a clean, modern, and highly usable interface, the application follows a strict, minimal design system based on your brand parameters.

    Background Color: Pure White (#FFFFFF) dominates the workspace to ensure maximum legibility and a spacious, distraction-free layout.

    Primary Accent/Button Color: Safety Orange (#FE4D00). This high-contrast color is reserved strictly for primary calls to action (e.g., "Confirm Booking", "Find Free Desk"), immediately drawing the eye to interactive elements.

    Border Radius: Standardized at 10px across all UI components—including input fields, cards, modal popups, and buttons—to create a cohesive, soft-geometric interface rhythm.

    Typography: System Sans-Serif stack (system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif). This ensures instant load times, zero external font dependencies, and excellent readability across all devices.
